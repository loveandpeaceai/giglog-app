常见问题（FAQ）

Q：如何恢复购买？

A：打开App → 进入"设置"-"解锁"页面 → 点击"恢复购买"按钮。请确保您使用的是购买时的同一个Apple ID。

Q：购买后没有生效怎么办？

A：请先尝试点击"恢复购买"按钮。如果仍然没有生效，请发送邮件至客服邮箱，附上您的Apple ID和购买凭证截图，我们会协助您解决。

Q：如何申请退款？

A：所有内购交易均由苹果公司处理，退款申请请直接通过苹果App Store提交：打开App Store → 点击头像 → 选择"已购项目" → 找到本App → 点击"报告问题" → 选择退款原因并提交。

Q：如何取消自动续费？

A：打开iPhone的"设置" → 点击您的Apple ID → 选择"订阅" → 找到本App → 点击"取消订阅"。取消后，您仍可以使用订阅服务直到当前周期结束。

Q：App崩溃或闪退怎么办？

A：请尝试以下步骤：
1. 关闭App并重新打开
2. 重启您的iPhone
3. 更新App到最新版本
4. 更新iOS系统到最新版本
如果问题仍然存在，请发送邮件至客服邮箱，附上您的设备型号和iOS版本号。

Q：数据丢失了怎么办？

A：本App所有数据都存储在您的本地设备上，我们不会备份您的数据。建议您定期通过iCloud备份您的设备。

Q：有功能建议或意见反馈？

A：非常欢迎您提出宝贵的建议！请发送邮件至客服邮箱，我们会认真考虑每一条反馈。
